# SignalSight

A Wi-Fi surveying application that visualizes wireless signal
strength and helps identify weak coverage areas.

## Tech Stack

- React + TypeScript + Vite
- Python + FastAPI
- JSON storage

## Project Structure

- frontend/ - React web application
- backend/ - Wi-Fi scanner and API

## Frontend Setup

cd frontend
npm install
npm run dev

## Backend Setup

cd backend
pip install -r requirements.txt
uvicorn main:app --reload
